## v1相对v0的设计差异及此次暴露的问题

1. v0按来球曝光推高速度，上限2m/s；v1需严格成功，计划上限5m/s，当前实际仍0.8m/s。
2. v0距离从0.5–0.7m逐步到1.3–2m；v1从头就固定1.3–2m。对慢球而言，理想锚点到达时间约1.6–5s，使随机初始化早期更难遇到有用击球样本。它对已会踢球的v0权重有效，但不能据此前的warm-start smoke推断随机初始化也能顺利起步。这个从头训练难度在之前实现中估计不足。
3. v1加严的是**课程晋级判据**，不是PPO奖励。网络、奖励和恢复门控保持v0；没有增加与主动击球+稳定恢复相匹配的额外学习引导。更严格的验收不会自动产生更好的策略。
4. 恢复门控要求连续低关节速度，与此轮策略保留的探索噪声不匹配，产生长期等待后超时的循环。

## 建议的修复顺序（本次未改训练）

- 优先让恢复阶段的探索与稳定门槛兼容，例如阶段相关的探索强度，并保持PPO动作分布/log-prob处理正确；不能仅在环境外随意缩动作而忽略训练分布。
- 针对从头训练补充可见、可交互的基础接球/击球引导，及和严格成功一致的恢复/主动击球反馈；不能简单重新引入之前已发现有盲区的极近距离分布。
- 保留80%门槛，先建立非零且持续的严格成功，再观察课程自然晋级；当前没有证据支持仅增加迭代数便会解决问题。
