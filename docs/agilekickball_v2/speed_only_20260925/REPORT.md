## 改动机制

旧v2并非只增大速度：距离按固定控制时钟增长，速度和挑战采样也继续增长；恢复另加锚点约束、自适应驻留和从kick计时的截止。即使联合成功为0，时钟仍把速度上限推到6m/s。此前相同checkpoint回放和本次数据支持：基础学习分布过早变化，策略形成“单次踢球随后失稳”的行为；不是把episode上限调大就能解决。

早期在速度上限仍0.8m/s时旧v2已经退化，见 [先前只读审计](../stability_audit_20260924/REPORT.md)。因此不能只归因于6m/s，更不能为各项改动分配未经训练消融验证的独立因果效应。

本次删除v2自定义恢复与采样路径，直接继承v1的tick/reset/serve/balanced；环境和runner配置除startup/experiment_name外与v1逐项一致。未训练schema4的分阶段奖励也撤回到v1，以便只比较速度课程变化。v0/v1源文件不改。

新课程保持v1曝光起步与距离；每6000控制步观察连续发球表现，达到80%恢复份额和60%kick代理份额、累计曝光60000后解锁快速扩展。扩展需288000有效控制步（满倍率12000轮），上限6m/s；恢复≤50%、无kick代理或样本不足暂停提速。恢复窗口仍为稳定0.3秒、冷却0.4秒、球结束后最多等5秒。详见 [设计](../DESIGN.md)。
