## 深度管线与已修复项

训练和s2s均为：torso **link** frame安装，48×27，垂直FOV 58°，近/远0.1/3 m，米制沿射线距离，解析球体，无地面或自遮挡，无v4深度噪声；8帧从旧到新，每20 ms更新，reset重复首帧。CNN直接接收米制深度，导出内包括编码器和ball feedback；没有遗漏额外除以3或图像归一化。图形窗口10 Hz刷新不改变策略50 Hz深度历史。

发现：保存的相机四元数范数平方为`1.00011796`，并非严格单位长度。原s2s使用旋转矩阵转置；训练使用完整世界相机四元数乘法，再`quat_inv`除以范数平方后`quat_apply`。现已在`policy_depth()`复现训练float32运算，保留原相机参数，未简单归一化常量。
