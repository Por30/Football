# FindBox wall11：带深度噪声、圆柱和随机墙的拾箱原地保持

2026-10-24。任务 `Template-Perceptual-Ball-CarryBox-Walled11-v0`，独立于 wall10，继承已优化的 wall10 物理、策略、PPO/AMP 和 reset 流程。实现及CPU/真实仿真短测已通过；本次不启动 wall11 正式训练，已有 wall10 正式训练保留。

## 从初始化到回合结束

1. 创建4096个环境；每个环境有29关节G1、变尺寸箱子、地面、三根圆柱、一面墙，pickup参考起点可能有箱底支撑板。箱子实际尺寸为xy各0.21–0.39 m、z 0.15–0.35 m，密度10–100 kg/m³；尺寸与密度按环境在创建时采样，深度与物理使用同一箱体。
2. 每回合重新随机选择起点：20%默认站姿、80%动作参考初始化（RSI）；RSI内部loco/pickup/hold比例为2/3、1/6、1/6。总期望比例约20%/53.33%/13.33%/13.33%，是随机概率而非固定环境配额。默认和loco箱子落地，位置在机器人前方±45°、0.7–2 m；pickup/hold保持配对参考箱位，并作接地修正。hold可能已经抱箱，不能当作从地面拾箱。
3. 在本回合机器人—箱子中点周围重新摆墙柱，保留初始接近和抓取空间。捕获带噪深度，重置历史与动作延迟队列；历史用重置首帧填充，不拼接上一回合图像。
4. actor每20 ms（50 Hz）依据本体历史和深度历史输出29维关节动作。动作缩放0.25、原始动作裁剪±100；通过0–20 ms动作延迟、200 Hz显式PD和实际电机限幅驱动机器人。
5. 策略接近箱子、双手抬起，在箱子初始位置附近直立持稳。没有搬运终点、放箱、松手或恢复空手站姿阶段；也没有向策略输入阶段编号。
6. 严格保持条件连续满足2秒，即100个控制步后记成功。成功后继续保持；倾倒、骨盆/头/髋过低、箱子超速或20秒超时结束并重置。

严格成功要求同时满足：双手箱体接触力均>1 N，箱底离地>0.10 m、箱心高度≥0.70 m；箱子/机器人竖直方向点积分别>.8/.95，mid360连杆原点高度>1.05 m；机器人水平速度<.15 m/s、偏航角速度<.3 rad/s、箱子速度<.15 m/s；箱子距回合初始位置的水平漂移<.35 m。任一条件中断，连续计时清零。日志分default/loco RSI/pickup RSI/hold RSI，并单独记录初始箱底离地<3 cm的地面起点成功比例。

## 圆柱、墙和深度噪声

三根圆柱的半径0.15 m、高1.8 m；墙厚0.2 m、长8 m、高3 m。使用项目已有锁定六自由度的动态刚体：有实际碰撞，重置通过PhysX tensor传入位置与零速度；相机读取相同刚体位姿，墙柱可真实遮挡视线。墙的长边沿圆周切向，避免穿过初始操作区。

布局保护盘以机器人—箱子中点为圆心，覆盖所有机器人连杆原点外扩0.5 m，以及箱体水平包围圆/0.4 m支撑板外扩0.1 m。柱环半径为`max(保护盘半径+0.35, 1.35)+U[0,0.35] m`。三柱大体相隔120°，每柱再扰动±15°；整体参考机器人朝箱方向随机±60°。墙在柱环外0.45–0.8 m，方向随机0–360°。柱表面到保护盘至少0.20 m，墙面到任何圆柱至少0.20 m。这里提供周围视觉与碰撞干扰，不故意在机器人和箱子之间生成封死的路线；运动中仍可能接近或撞到障碍。

深度继续使用优化后的Warp光轴深度：48×27，4帧，单位米，范围0.1–3 m，缺测填3 m。遮挡包括机器人自身、地面、墙、三柱、支撑板和实际变尺寸箱体。沿用现有`corrupt_depth_m`：

| 项目 | wall11参数 |
|---|---|
| 高斯噪声 | 标准差0.02 m |
| 深度相关噪声 | 标准差`0.008 + (0.03−0.008)×depth/3` m |
| 深度边缘 | 相邻深度差>0.15 m，边缘像素5%概率丢失 |
| 随机空洞 | 所有像素2%概率丢失 |
| 无效/丢失像素 | 保持3 m，其他结果截断到0.1–3 m |

每个环境每个控制步只生成一次噪声，重复读取不再抽随机数；终止帧也使用同一带噪图像，partial reset只使重置行缓存失效。4帧历史保存过去真实捕获的带噪图像。不新增深度随机延迟、冻结帧或相机安装扰动。上述深度噪声在训练与默认play中均启用。

## 每轮如何训练

- 默认4096环境×24步=98304条transition/轮，覆盖每环境0.48秒；24步是rollout长度，不是回合长度。配置独立保存到`logs/rsl_rl/g1_carrybox_depth/walled11/`，默认20000轮、每500轮保存checkpoint。
- 先用当前策略采样24步，保存actor/critic观测、动作、对数概率、奖励、终止和AMP历史。超时bootstrap使用重置前的真实终止观测；重置历史与平滑不跨回合。
- 奖励沿用wall10：接近箱子、抬箱、直立保持，加速度/动作变化/力矩/关节速度/限位正则不变。环境task奖励先按0.02 s积分，最终回报为`0.75×task_reward + 0.125×style_reward`。新增墙柱不增加新奖励或阶段。
- 使用gamma=.99、GAE lambda=.95计算优势和回报；PPO每轮5 epochs×4 minibatches=20次联合Adam更新，clip=.2、value coef=1、entropy coef=.01、AC梯度上限1。初始学习率1e−3，根据KL目标.01自适应调整。
- actor/CNN/critic与AMP共用联合Adam，保留原AMP权重衰减、LSGAN、专家梯度平方惩罚和无Normalizer设置。时间平滑系数policy=1/9、value=1/90；24步rollout前23步可配相邻样本，done边界不平滑。
- AMP数据仍是`assets/motions/findbox/`中15段：11行走、3完整pickup、1原地hold。按片段权重1/4/5采样，总权重11/28、12/28、5/28；原生60 Hz插值至50 Hz，速度倍率.95–1.05。RSI初始化比例与AMP专家采样比例是两件事。
- 保留wall10性能优化：Warp射线与变尺寸箱体解析求交、学习执行批合并、逻辑256随机采样块及8192执行批、无RTX深度渲染；不通过减少5×4更新来提速。
- 原有随机化保持：Kp/Kd/motor strength乘.9–1.1，力矩偏置±5%；连杆质量×.8–1.2并重算惯量，torso COM各轴±.1 m，机器人摩擦.1–1.5、恢复系数0–1；每8个控制步施加一次torso各轴±50 N的单物理步脉冲。

wall11继续schema2，但环境契约独立记录walled11/revision1、噪声、几何、布局和缓存语义。wall10 checkpoint不能作为wall11严格resume；如以后迁移已有权重，应显式使用warm start而不是冒充完整恢复。本次没有迁移权重或启动正式训练。
