# Wall5平均回合长度诊断 · 2026-10-16

当前证据指向两个问题：**推扰强度超过当前策略的恢复能力；策略虽然能走，但没有可靠地向箱子接近并完成拾取。** AMP阶段A已经提供有效奖励，旧版普遍reset后3步倾倒的现象没有在本次回放中复现。不能将当前停滞简单归为AMP失效、PPO学习率太低或探索噪声太大。

此次只新增诊断文件，未修改生产代码、模型、数据或停止/重启训练。正式PID2996727保留。21:57 JST检查到7396轮，最近100轮日志平均回合290.00步（5.80秒），相较此前175步正在回升，尚未接近1000步/20秒上限。诊断共用GPU期间正式耗时暂时升高，退出后恢复约4.09秒/轮；不能将并发诊断期间速度当成性能回归。

### 推扰是当前短回合的重要因素

两种动作模式中，关闭推扰均明显增加存活和超时记录；同样19200个环境步内，跌倒或倾倒回合分别由56降至15、61降至16（重叠谓词按OR去重）。loco完成均值分别由341.67→633.70、318.39→651.82步。当前push每1–3秒将root的六维速度设置到采样值，最大范围XY±0.5m/s、Z±0.2m/s、roll/pitch±0.52rad/s、yaw±0.78rad/s。课程1000轮后开始，5000轮达到满强度，按迭代推进，不等待机器人学会稳定接近或拾箱。直接回放支持“当前checkpoint对该推扰敏感”，但不能单凭训练曲线同期变化证明历史回落全部由push造成。

单去动作采样，在有推扰时277→240步，无推扰时531→546步，未显示整体寿命的明显改善。确定性动作仍保留深度噪声，不能称无噪声对照。它确实改善了部分直接抱箱的短时成功表现，因此也不能说探索噪声对接触保持毫无影响。

### 延长回合没有自动带来任务进展

行走起点状态统计：有push的采样组平均距箱2.14m，近箱（XY<0.7m）占15.68%；无push采样组平均距箱6.47m，近箱13.48%；无push均值动作组平均距箱6.34m，近箱13.07%。四组loco的箱高>0.6m状态比例都是0，完成与仍存活回合的loco成功均0。可见策略在无推扰下可以保持更长的行走，却经常远离箱子，没有可靠地把模仿步态转化为目标接近和拾取。

当前reward中近箱walk固定1.5，carryup在尚未抬箱时也有高度/接近的正值；standup须箱高>0.6m等条件成立才开启。这些沿用wall4/X2的任务项可能支持局部行为，尚未通过改奖励对照证明各项贡献。wall5本轮只改AMP阶段A，PPO、任务奖励和上述课程仍沿用父任务；AMP有效不等于整套G1迁移已完成收敛。

严格成功必须分开看来源：采样两组完成及存活均0；有push均值组pickup有1个完成回合成功、hold有5个完成回合成功；无push均值组hold有3个完成回合成功，另有2个仍存活hold回合已成功。它们来自参考拾取/直接抱箱初始化，均不代表完整从地面找箱抬起；成功也不终止回合。这解释了局部保持动作存在而整体流程仍未学会。

### 未复现旧的立即reset错误

四组所有已完成回合均没有≤10步结束；初始/reset时实际姿态和高度没有立即违反终止条件。终止前直接读取root roll/pitch、root高度和实际head COM：当前结束由真实跨过配置门槛引起，未发现旧head原点误用或计数错误重现。tipped阈值|roll|>0.5rad或|pitch|>1.1rad；fell为root<0.2m或head COM<0.4m。短测不能排除所有初始化或物理问题，也不证明跨阈值后绝无恢复可能。

## 日志口径与仍待验证项

- `Mean episode length` 是runner最后100个完成回合的实际步数，单轮显示会受技能组成影响；`Skill/*_mean_steps`是整个进程累计均值，再经过24步日志聚合，不能当成同一个时间窗口。
- 本机IsaacLab `Episode_Termination/*`是每个环境保留的最近终止标签再对4096环境取均值；多终止条件同时成立时后声明项覆盖先前标签。固定窗口日志tipped64.25%、fell29.27%、timeout6.48%是这个指标，**不是该窗口新完成回合的精确百分比**。本次回放保存实际谓词，tipped/fell/timeout可能同时为真，不能强制相加为100%。
- `Mean reward`仍是环境原始任务奖励；PPO使用的混合奖励看`Reward/*_per_step`。回放`state_means.style`是动作前状态评分（含reset帧，未含每个terminal帧），也不能直接替代训练transition的AMP奖励。
- 辅助位置MSE在固定最近窗口约1.523，乘0.5后位置/旋转总辅助loss约0.783；回归对全部帧启用，包括箱子不可见/离开有效范围的帧。它与actor/critic共享CNN和全局梯度裁剪，属于值得进一步核对的学习干扰候选。loss数值不能证明梯度占主导，本次未做梯度分解或辅助头消融。

后续改进优先按站稳/接近能力逐步开放推扰，并检查朝箱移动、制动接近、双手拾取与保持的任务信号；之后再验证辅助监督在不可见帧的处理及PPO配置。保持无特权actor/critic、真实遮挡和原成功口径。本次没有实施这些训练改动。
