## 可能原因及证据强度

1. **任务信号允许未拾起的局部行为。** 当前水平距离<0.7m就固定得到walk=1.5；carryup的手中心接近与绝对高度指数项在未接触、未抬箱时已有正值。接触项取两手分数均值，单手接触也有贡献；手位置项只看双手中心，未分别约束两手夹在箱子两侧。standup需要箱心>0.6m等条件才打开。与stable_grasp近零一致，但尚无奖励消融证明哪项是主因。AMP有效并不会自动完成目标导向拾取；91.7%净占比也可能来自任务项正负抵消，不能据此直接断言AMP系数必须减小。
2. **RSI起点与地面拾箱任务不一致。** 30%回合在三段pickup中均匀抽片段、随机抽帧，包括接触前、抬起后和后续转身。初始化设置机器人位置及速度，箱子速度却清零；数据无箱子姿态，非loco箱体姿态仅采用机器人yaw。因此手箱接触与相对运动不保证物理可保持。支撑台由contact_index推算，并非真实支撑台标注。以下CPU数值尚未加实际脚底接地修正，也未加采样帧上限裁剪，不能冒充最终仿真台高。

3. **推扰会打断尚未稳定的接近/抓取。** 每1–3秒设置一次root六维速度；1000轮开始、5000轮满强度，不以抓取成功作为进阶条件。XY±0.5m/s、Z±0.2m/s、roll/pitch±0.52rad/s、yaw±0.78rad/s。先前[model7200四组回放](../wall5_length_20261016/README.md)中，关闭push使完成回合均值约277→531步、240→546步，但loco仍无成功且经常远离箱子。这是旧checkpoint的直接证据，不是model20600的新对照。
4. **G1实际抓取与X2奖励尺度仍需进一步适配。** 当前是29DOF、无手指的固定rubber-hand，靠双手接触摩擦托举，没有自动吸附/焊接。近箱时每手力超过7N开始受软惩罚，不是物理限力；箱子质量每回合0.08–1.2kg、材质也有随机化。是否限制了足够夹持力需测双手法向/切向力，不能由7N直接判定抱不动。wall5原阶段A主要修复AMP；G1的奖励门控、PD相关惩罚、PPO及共享视觉编码器仍存在适配候选。所有帧都做位姿监督，包括不可见帧，可能产生学习干扰，但没有梯度分解证据。
5. **全身碰撞是新的环境分布。** revision10增加/补齐肩、膝、腕、头、骨盆等几何，revision9旧模型没有在这些接触条件下训练过。可能改变近箱蹲起和手臂接触，不能将新环境的播放表现作为原训练环境表现；也不能把新增几何解释成此前20786轮失败的原因。

## 实际终止条件

每个policy步（0.02秒，4个物理子步）后检查，任一满足即只重置对应环境，没有姿态持续超限的缓冲时间：

| 条件 | 实现 |
|---|---|
| time_out | episode计数达到1000步，正常20秒 |
| tipped | root/骨盆 `abs(roll)>0.5rad`（28.65°）或 `abs(pitch)>1.1rad`（63.03°） |
| fell | root离地<0.2m，或**实际head COM**离地<0.4m |

roll/pitch取root姿态，腰关节弯曲本身不等同于触发tipped；身体没接触地面也可能先跨过姿态阈值。头部使用COM，旧head-link腰部原点问题已修复。手、膝或全身碰撞不是独立终止条件，髋/膝不期望接触有奖励惩罚。

`invalid`名义上注册为终止项，但实际非有限状态/动作会抛`FloatingPointError`停止运行，不是悄悄reset。成功、箱子掉落、没找到箱子、机器人离箱较远都没有单独终止条件。正式train会随机化最初一批的超时年龄，首批可能早于20秒timeout；后续正常reset从0计时，实际步数指标独立记录。

成功仅奖励/统计：箱底离**地面**≥0.12m、两只rubber-hand对箱子接触力各>1N、箱子upright>0.9、线速度<0.25m/s，连续25步/0.5秒。达到成功不reset。该指标并不要求相对初始化高度或平台高度继续抬升，因此高支撑台pickup与直接hold的成功不能算从地面完整拾起；本次未声称已观察到平台刷分。

## reset顺序和分布

1. 先记录本回合成功/终止/实际步数，并保存reset前terminal本体、深度、AMP历史，供PPO timeout bootstrap与AMP使用。
2. Isaac管理器清理场景缓存，执行root/joint常规reset；随后`reset_scene`按loco60%、pickup30%、hold10%选择初始化类型。默认开启RSI，因此参考root/关节位置和速度覆盖前面的常规随机reset。参考去除全局yaw，并用实际脚碰撞凸包把最低脚点向上补足到离地5mm；不会把已高于地面的脚强制向下压。
3. 清零成功保持、search和配对深度缓存。loco箱子前方±45°、半径0.7–2m，倾斜±30°、yaw按课程；其中2%loco（总体约1.2%）改为视野外±60–180°、距离0.9–2m。pickup/hold采用同一参考帧箱位置，姿态只保留yaw，所有箱速度清零并防止初始穿地。
4. 平台XY跟随箱子，pickup按上述参考推算台高并裁剪到不高于箱底；loco/hold平台顶面设在地面。再采样墙（3–4m）及3圆柱（2.2–3.2m），重设相机安装扰动。
5. reset事件随机箱子质量并重算惯量；材质、躯干COM和默认关节偏置是startup随机化，不是每回合重采样。管理器清理动作、观测历史等缓存，episode计数归零，再计算新回合观测。wall5 AMP reset历史重复首帧，首个transition即参与AMP。

loco/pickup/hold没有强制阶段切换；它们只是起点标签。actor/critic仍只读取深度与本体，箱子真值用于奖励/辅助监督/统计，不进入策略价值输入。

建议后续先做无push、固定质量/材质、明确地面起点的G1手箱接触诊断，分别统计接近、双手接触、离地和保持；再调整任务奖励及课程，最后恢复随机化。保持真实深度遮挡和无特权观测。现阶段不宜只放宽reset阈值或继续增加训练轮数，也未实施这些改动。
