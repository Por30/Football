## 与奖励的关联，尚未做训练因果验证

最近100轮空手原始任务奖励约−0.0296/步。其中walk约+0.0163，torques约−0.0179，action_rate约−0.0139，后两项已经超过walk。初期空手持续生存得负回报，可能形成偏向提前结束的激励；随机reset又使实际采样逐渐偏向更长的pickup/hold回合。但这属于由日志支持的机制假设，不等于已证明策略有意“刷reset”。

PhysHSI力矩惩罚使用`sum((torque/p_gain)^2)`，当前仍为原始`sum(torque^2)`；本轮仅记录这一既有差异，未修改奖励权重。AMP或辅助监督也不能仅凭这些回放认定为唯一根因。
