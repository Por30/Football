**公式相同，实际力矩惩罚不同**：说明轨迹/状态/接触或动作分布不同，不能颠倒为“惩罚变大一定导致策略先失败”。它可能是失稳结果，也可能参与放大失稳，尚需隔离验证。

Rev22在6300–6399轮整体平均回合886.88步，近期空手约878.73步；用户指定视频的3个空手起点都走近箱子并跑满20秒，但未拾箱。这证明该力矩项下可以学会行走。当前尚无6400轮数据，不能把两个不同训练阶段直接当作同进度对照。

**AMP判断也要收窄**：Rev22在上述已能行走阶段，style平均仅0.02363，与当前0.02091处于相近量级。因此不能仅凭低style或专家/策略容易分离，判定它是行走失败原因。两run的判别器参数不同，分数不是统一校准的性能量尺。

## 真正发生的变化与下一步重点

1. **Rev23改了接近/抓取奖励。** Rev22进入3D近箱区（约0.784m）后walk固定1.5；Rev23起取消该满值，改为速度衰减、0.52m站位和拥挤惩罚，并将carryup改为箱面距离、双手接触/抬升组合，近箱3D范围改0.90m。不能直接恢复旧满值后就声称拾箱问题解决，因为rev22也会在箱旁停滞。
2. **自碰撞、碰撞几何和接触计分变了。** Rev22全身凸包、关闭自碰撞；Rev23开启自碰撞而髋膝惩罚计入自接触，旧审查已验证这一点；当前Rev26已改为PhysHSI碰撞几何，开启自碰撞并移除该接触惩罚。不能把已移除的项继续称为当前有效惩罚。
3. **AMP专家数据与RSI分布变了。** Rev22使用ground_pickup数据子集、固定75/5/20配额和地面pickup03的0–31帧；Rev23恢复完整三pickup的专家数据；Rev24起reset为20%默认+80%随机RSI（总体约20/53.3/13.3/13.3），完整pickup连续起点及支撑台，根速度覆盖为各轴±0.2。
4. **Rev24起增加0–20ms动作延迟和新的reset扰动/限位处理，终止测量点也改为PhysHSI。** Rev26再修正最终关节扰动后的脚底接地。这些均不是rev22的控制/reset分布。

已有[Rev23退化审查](../wall5_walk_diagnosis_20261022/README.md)显示，同到6400轮，rev22整体回合约887步、rev23约50步，退化在PhysHSI reset迁移之前已经出现。因此后续应首先以rev22→rev23的奖励/碰撞/专家数据变更为范围定位，再核查rev24之后的reset/延迟是否进一步放大；暂不将力矩归一化列为已确定修复。当前没有做单变量重训，不能从本对照确定哪一项为唯一根因。
