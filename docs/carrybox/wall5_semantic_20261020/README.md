## 几何依据

`geometry.json`保存当前G1资产的PhysX参考姿态FK读回；将实际脚凸包最低点放到地面，未进行动态站稳实验。行走11段各取64帧，共704帧，其中580帧满足projected-gravity XY < 0.2；逐片段取中位数后再取11段中位数，骨盆0.773153m、头COM 1.219626m。持箱32帧均满足该直立条件，箱心中位数0.850790m，手中心距参考箱心最大约0.05422m。

拾取参考共104帧，最低骨盆0.348424m、头COM 0.662100m，均高于新低高度终止阈值。此检查只针对高度终止，不代表所有参考姿态都满足roll/pitch或动态稳定条件。初次16帧/行走片段的粗采样只有139帧满足直立筛选，未达到预设150帧下限；扩大到64帧后得到580帧，没有放宽筛选或样本下限。

X2比较锚点来自用户提供的报告：骨盆0.669m、头0.823m、持箱中心0.729m。本次没有运行X2仿真或验证其源码。水平箱体中心贴地高度按现有0.25m厚箱体为0.125m；reset的5mm安全间隙和箱子倾斜会让实际站立边界略有偏移。

3D门槛按 `sqrt(0.7²-(0.669-0.125)²+(G1骨盆-0.125)²)` 计算，保持参考站立条件下水平范围0.440527m。旧0.7m门槛在本次G1锚点下只有约0.264m水平范围；新值仍是3D距离门控，不是改回2D。

骨盆阈值乘 `G1骨盆/0.669`，头阈值乘 `G1头COM/0.823`；箱高以地面箱心0.125m为零点，按持箱提升行程 `(G1持箱箱心-0.125)/(0.729-0.125)` 缩放。相应高度指数系数按长度比例的倒数变化，保留归一化误差对应的曲线形状。头部目标继承X2的0.85/0.823比例，略高于参考头高；它是平滑奖励目标，不是终止条件。

## 奖励与边界

- 去掉独立 `locomotion_stability` 权重5项，以及walk上的稳定性乘法。保留历史诊断函数用于旧数值回归，当前RewardManager不注册它，日志也不再索引它；新增loco的carryup/standup分项日志。
- walk仍奖励0.85m/s朝箱水平骨盆速度与朝向；方向按XY归一化，阶段按XYZ门控。保留接近后walk=1.5的原公式，不额外改任务权重。
- carryup仍由手中心靠近、双手对Box接触和箱高组成；standup用骨盆姿态与骨盆COM速度表达在骨盆坐标系中，search转向速度也用骨盆系。避免躯干/腰部摆动充当骨盆整体运动。
- 手接触仍使用Box过滤的force_matrix_w。手距离、接触力阈值、手臂速度/加速度阈值和奖励权重不变；全部奖励仍只由RewardManager乘一次weight×policy dt。
- 即时standup奖励门控与严格成功统计分离。严格成功的接触、箱底离地、姿态、速度及持续0.5s条件保持原实现，不能把即时奖励激活称为拾箱成功。
- roll仍为双向abs(roll)>0.5rad（约28.65°），pitch为abs(pitch)>1.1rad，超时20s；一次性失败惩罚weight=-50保持。仅低骨盆/低头高度终止随几何缩放。
- actor372维本体历史+4×27×48深度；critic独立108维特权MLP；训练AMP10×60。动作std上限/动作界正则、RSI固定80% loco/20% hold、hold参考箱高、增量推扰课程、摩擦、全身碰撞和深度噪声保持。
- checkpoint schema仍为2，环境契约revision19记录全部实际阈值/标定/frame。rev18严格load（含load_optimizer=False）被拒绝；本次正式从零，不恢复旧权重或优化器。
