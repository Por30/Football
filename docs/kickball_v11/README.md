# Kickball v11：wall11框架的连续接球回传

2026-10-25 12:03 JST：实现与短测完成。独立任务ID为 `Template-Perceptual-Ball-Kickball-v11`，revision `wall11_return5_aux_standing_v1`。215项CPU测试及16环境、24步rollout的2＋1轮更新/严格恢复/导出通过。尚未启动正式训练，未评估回传成功率或4096环境性能。

## 用户确认的任务

继承wall11的机器人、显式PD、动作延迟、物理随机化、深度噪声、历史观测、非对称AC和联合PPO/AMP框架。移除箱子、平台、墙和三根圆柱，场景只有G1、球和地面。动作数据读取已有 `assets/motions/kick/kick_left.pt`、`kick_right.pt`，原数据未修改。

全部回合从固定站立关节姿态、零关节/根速度开始，按实际足部碰撞凸包作5 mm向上接地修正。没有参考动作初始化。重置同时清理历史与动作延迟FIFO；同一回合连续执行“来球→回踢→恢复站稳→再次发球”。左右脚由策略自主使用，不输入踢球脚命令或阶段编号。

球半径0.11 m、质量0.43 kg，沿用足球球体材料和阻尼。每轮从机器人初始朝向±0.35 rad、距离1.3–2 m发球，瞄准横向偏移±0.25 m，初始角速度匹配地面滚动。来球速度课程从0.4–1.1 m/s开始，沿用v4恢复/击球门控，最高0.4–5 m/s。播放速度覆盖也不得超出0.4–5 m/s。

回传目标沿用v4：保存本轮发球点，在该处建立垂直来球方向的目标门；半宽由0.6 m按表现逐步收紧到0.2 m。成功需要本轮有足部击球资格、球单向反穿目标门、向外速度>0.4 m/s、过门高度≤0.35 m、横向误差在门宽内且机器人当步未终止。过门位置用相邻步线段插值；首次过门后不再重复给命中奖励。足部资格仍使用“最近踝关节原点距球<0.30 m且平面速度跳变>0.15 m/s”的代理，不能当作接触力真值。

球距初始锚点>3 m、滚到机器人身后或速度<0.15 m/s时结束该轮。机器人随后须满足v4平衡判据连续0.3秒，且等待至少0.4秒才再次发球；等待5秒仍未恢复则重置。机器人活动半径0.6 m；保留wall11倾倒/低位终止和20秒回合上限。每个回合可包含多次发球，回传成功不立即重置机器人。

## 观测与辅助预测

| 分支 | 内容 | 维度/用途 |
|---|---|---|
| Actor本体 | 角速度3、投影重力3、关节位置29、关节速度29、上一步动作29，历史6帧 | 93×6=558；保留wall11本体噪声 |
| Actor深度 | 完整机器人、地面、球的Warp光轴深度，带wall11噪声 | 4×27×48；米制0.1–3 m，缺测3 m |
| Critic | 当前无噪本体93、双掌/双踝/mid360相对骨盆15、局部根线速度3、球状态6、发球点相对位置3、回传法向3、门半宽1 | 124维独立MLP，训练专用 |
| 球状态辅助标签 | 球相对根连杆位置3、球相对根连杆的惯性速度3，均旋转到当前根坐标系 | 6维，单位m和m/s；仅监督 |
| AMP | 既有足球60维特征、历史10帧 | 600维，仅判别器与风格奖励 |

辅助速度定义为 `R_root^-1 (v_ball_world - v_root_link_world)`；这是相对惯性速度的机体系表达，不额外减去旋转坐标系的角速度叉乘项。辅助头输入与actor相同的本体/CNN特征，输出位置和速度6维；训练损失为：

`1.0 × [mean((预测位置−真值位置)^2) + mean(((预测速度−真值速度)/5)^2)]`

损失在联合Adam的同一次minibatch更新中训练CNN和辅助头，使用与current rollout观测对应的全部标签，包括遮挡或不可见球。标签不参与动作前向，预测结果也不额外拼入actor。Critic损失只训练独立价值MLP。JIT/ONNX导出仅有本体历史和深度历史两个输入，包含encoder＋actor，不包含Critic、辅助头、AMP或真值。

深度沿用wall11的0.02 m高斯噪声、0.008–0.03 m距离相关噪声、边缘5%丢点及2%随机空洞；每环境每控制步生成一次。重置或同一步再次发球使对应行缓存失效，未重置环境的历史不变。终止观测在重置前捕获，供timeout bootstrap与AMP使用。

## AMP和训练

两段已有踢球动作约120 Hz，左498帧、右589帧，等概率采样，插值到50 Hz，速度倍率0.95–1.05。沿用足球数据的命名关节顺序与 `wrist_roll/ankle_pitch/head_link` 五末端，区别于搬箱的掌心/mid360定义；实际仿真已核对五个连杆解析。每帧为高度1、关节29、末端15、线速度3、角速度3、去航向旋转6、零物体槽3。原动作没有球轨迹，专家和策略两侧球槽均为零。数据SHA256及特征语义写入checkpoint契约。

保留wall11单个无Normalizer的AMP判别器、联合Adam、LSGAN、梯度惩罚和时间平滑。奖励混合为 `0.75×task_reward + 0.125×style_reward`；task先由环境按0.02秒积分，style不重复乘dt。任务奖励使用v4的站稳/朝球/接近、方向稠密奖励、一次击球奖励、一次过门奖励及漏球惩罚；动作变化、力矩、关节速度/加速度/限位正则沿用wall11。径向击球代理只用于原球速课程；目标门命中和固定±0.2 m命中分别统计。

默认4096环境×24步，PPO每轮5 epochs×4 minibatches，初始学习率1e-3、KL自适应、gamma0.99、lambda0.95；Actor/Critic为512→256→256。控制50 Hz、显式PD200 Hz，动作scale0.25、clip±100，0–20 ms延迟。保留wall11增益/电机强度0.9–1.1、力矩偏置±5%、质量/COM/接触随机化，以及每8个控制步一次torso各轴±50 N单物理步扰动。默认20000轮，每500轮保存。

checkpoint继续使用共享schema2序列化，新增 `kickball_v11_schema=1`、独立环境/AMP契约及 `kickball_v11_curriculum`。严格恢复检查数据身份、网络/目标配置和速度/方向课程；恢复后重建物理回合，首轮即使用恢复的球速与门宽。播放冻结课程。旧wall11、v4/v5模型不能直接严格恢复为本任务，默认从零训练。
