0. 复现验收标准

完成后应满足：

两个任务名能在 legged_lab/envs/__init__.py 中注册，且 train.py --task=... 可构建环境。
Actor/critic 观测维度与父任务 x2_findbox_depth_v2_5_random_finetune 完全一致；墙和圆柱只改变深度图内容，不新增观测维度。
每次 reset 后：
wall3：墙距离机器人 root 3.0–4.0m；3 个圆柱均距离 root 2.2–3.2m。
wall4：除 wall3 行为外，约 2% 的 loco 回合会把箱子移到相机视野外。
TensorBoard/日志中可看到 Curriculum/box_yaw_range_deg：
wall3：新训练进程中从 10° 线性升到 180°（8000 iter）。
wall4：0→10°→30°→180°（0/10k/20k/30k iter），随后保持 180°。
Reward manager 中启用的 wall3 新项为 held_hand_speed、held_hand_acc、waist_yaw_penalty，且 torque_limits 被移除；wall4 再额外启用 search_turn。

2.6 FindBox 箱子初始化（wall3/wall4 都继承）

普通 loco 回合：

findbox_depth 把箱子放在机器人前方：
距离 U[0.7, 2.0)m
bearing 相对 heading 为 U[-45°, 45°)
platform XY 与箱子同步
finetune 再覆写箱子姿态：
只对 loco 回合生效
box_pose_randomize_probability = 1.0
yaw：U[-yaw_range, yaw_range]，yaw_range 由 _box_pose_yaw_range_deg() 提供
tilt：roll/pitch 各自 U[-30°, 30°]
box_quat = quat_mul(yaw_quat, tilt_quat)
根据倾斜后长方体在世界 z 方向的半高度，把箱子底部放在地面上
箱子速度清零
platform 移到箱子 XY，z 为 ground_z - 0.025
倾斜长方体的世界 z 半高度：

half_height_z = |R[z, x]| * size_x/2
              + |R[z, y]| * size_y/2
              + |R[z, z]| * size_z/2

finetune 关闭了 v2.5 random 的箱子尺寸随机化，场景使用 replicate_physics=True。箱子默认尺寸 0.3 × 0.3 × 0.25m。箱子质量/摩擦随机化仍继承父类。

非 loco（实际只有 carryWith）回合使用 motion reference 给出的箱子状态，finetune 不改它的姿态。

_reset_boxes(env_ids) 必须按以下顺序：

    d ~ U[2.2, 3.2)
    theta ~ U[0, 2π)
    pos.xy = robot_root_xy + d * [cos(theta), sin(theta)]
    pos.z  = env_origin_z + 0.9
    quat   = (1, 0, 0, 0)

4.3 wall3 箱子 yaw 课程

覆写 finetune 的 _box_pose_yaw_range_deg()：

def _box_pose_yaw_range_deg(self) -> float:
    yaw_min = float(getattr(self.cfg.scene, "box_yaw_min_deg", 10.0))
    if not hasattr(self, "current_learning_iteration"):
        return yaw_min
    it = float(self.current_learning_iteration)
    if getattr(self, "_yaw_curr_anchor_iter", None) is None:
        self._yaw_curr_anchor_iter = it
    span = max(1.0, float(getattr(self.cfg.scene, "box_yaw_curriculum_iters", 8000.0)))
    f = min(1.0, max(0.0, (it - self._yaw_curr_anchor_iter) / span))
    return yaw_min + f * (180.0 - yaw_min)

要点：

OnPolicyRunner.learn() 每个训练 iteration 开始时设置 env.current_learning_iteration = it。
- 环境构造时的初始 reset 还没有这个属性，所以返回 10°，且不能在这里建立锚点。
第一次真实训练 reset 时，用当前 iteration 作为 _yaw_curr_anchor_iter。
从 checkpoint resume 时，课程从本次训练进程的起点重新开始，不会直接跳到 checkpoint 绝对 iteration 对应的难度。
这里返回的是半范围；实际 yaw 为 U[-range, range]。
只影响普通 loco 箱子。tilt 仍为 ±30°。
在 wall3 的 _reset_boxes 中，super() 后写日志：

if isinstance(self.extras.get("log"), dict):
    self.extras["log"]["Curriculum/box_yaw_range_deg"] = torch.tensor(
        self._box_pose_yaw_range_deg(), device=self.device
    )

5.2 分段 yaw 课程

def _box_pose_yaw_range_deg(self) -> float:
    iters = [float(x) for x in getattr(self.cfg.scene, "box_yaw_curr_iters", (0, 10000, 20000, 30000))]
    degs = [float(x) for x in getattr(self.cfg.scene, "box_yaw_curr_degs", (0, 10, 30, 180))]
    if not hasattr(self, "current_learning_iteration"):
        return degs[0]
    it = float(self.current_learning_iteration)
    if getattr(self, "_yaw_curr_anchor_iter", None) is None:
        self._yaw_curr_anchor_iter = it
    e = it - self._yaw_curr_anchor_iter
    if e <= iters[0]:
        return degs[0]
    if e >= iters[-1]:
        return degs[-1]
    for i in range(1, len(iters)):
        if e <= iters[i]:
            t = (e - iters[i - 1]) / max(1.0, iters[i] - iters[i - 1])
            return degs[i - 1] + t * (degs[i] - degs[i - 1])
    return degs[-1]

5.3 视野外 search 箱子

常量：

_HALF_FOV = math.radians(45.0)
_OOV_MIN = math.radians(60.0)

_reset_boxes(env_ids)：

def _reset_boxes(self, env_ids):
    super()._reset_boxes(env_ids)

    if not hasattr(self, "_search_env"):
        self._search_env = torch.zeros(self.num_envs, device=self.device, dtype=torch.bool)
    if len(env_ids) == 0:
        return

    self._search_env[env_ids] = False
    skill_names = list(self.cfg.amp_cfg.skill_init_prob.keys())
    if "loco" not in skill_names:
        return
    loco_idx = skill_names.index("loco")
    loco_mask = self._reset_ref_skill_idx[env_ids] == loco_idx

    p = float(getattr(self.cfg.scene, "search_prob", 0.05))
    pick = loco_mask & (torch.rand(len(env_ids), device=self.device) < p)
    if not pick.any():
        return
    sub = env_ids[pick]
    count = len(sub)

    forward = quat_apply(self.robot.data.root_link_quat_w[sub], self.forward_vec[sub])
    heading = torch.atan2(forward[:, 1], forward[:, 0])
    mag = torch.rand(count, device=self.device) * (math.pi - _OOV_MIN) + _OOV_MIN
    sign = torch.where(torch.rand(count, device=self.device) < 0.5, 1.0, -1.0)
    angle = heading + sign * mag
    dist = torch.rand(count, device=self.device) * (_OOV_DIST_MAX - _OOV_DIST_MIN) + _OOV_DIST_MIN

    root_xy = self.robot.data.root_pos_w[sub, :2]
    box_xy = torch.stack((
        root_xy[:, 0] + dist * torch.cos(angle),
        root_xy[:, 1] + dist * torch.sin(angle),
    ), dim=-1)
    self.box_states[sub, :2] = box_xy
    self.platform_pos[sub, :2] = box_xy
    self._search_env[sub] = True

    platform_rot = torch.tensor([1.0, 0.0, 0.0, 0.0], device=self.device).repeat(count, 1)
    self.platform.write_root_pose_to_sim(
        torch.cat([self.platform_pos[sub], platform_rot], dim=-1), sub
    )
    self.box.write_root_pose_to_sim(
        torch.cat([self.box_states[sub, :3], self.box_states[sub, 3:7]], dim=-1), sub
    )

行为细节：

只有 loco 回合参与抽样。由于 loco 初始化概率为 0.8，配置 search_prob=0.02 对全部 reset 回合的期望 search 比例约为 1.6%。
search 箱子 bearing 幅值在 [60°, 180°)，左右各半，因此初始在 ±45° 水平视场之外。
只改箱子/platform XY；箱子的 z、四元数和此前已清零的速度保留 finetune 结果。
- search 箱子重新放置后不会重新调用墙或圆柱 reset。墙距离机器人 3–4m，因此箱子不会在墙后；圆柱距离2.2–3.2m，而search箱子中心最多2.0m；这只分离中心半径区间，考虑箱体半尺寸、倾斜和圆柱半径后，不能保证表面绝不相交。
_search_env 只在 reset 时清零/重采样，回合中不会因箱子进入视野而改成 False；search_turn 自身用 bearing 门控关闭。
5.4`search_turn` 奖励

def _box_bearing_error(env):
    forward = quat_apply(env.robot.data.root_link_quat_w, env.forward_vec)
    heading = torch.atan2(forward[:, 1], forward[:, 0])
    to_box = env.box_states[:, :2] - env.robot.data.root_pos_w[:, :2]
    target_heading = torch.atan2(to_box[:, 1], to_box[:, 0])
    return torch.abs(wrap_to_pi(target_heading - heading))


def search_turn_reward(env):
    if not hasattr(env, "_search_env"):
        return torch.zeros(env.num_envs, device=env.device)

    bearing_err = _box_bearing_error(env)
    heading_reward = torch.exp(-0.75 * bearing_err)

    forward = quat_apply(env.robot.data.root_link_quat_w, env.forward_vec)
    heading = torch.atan2(forward[:, 1], forward[:, 0])
    to_box = env.box_states[:, :2] - env.robot.data.root_pos_w[:, :2]
    target_heading = torch.atan2(to_box[:, 1], to_box[:, 0])
    desired_dir = torch.sign(wrap_to_pi(target_heading - heading))
    yaw_rate = env.base_ang_vel[:, 2]
    turn_reward = torch.clamp(desired_dir * yaw_rate, min=0.0)

    reward = 0.7 * heading_reward + 0.3 * torch.tanh(turn_reward)
    active = (
        env._search_env
        & (bearing_err > math.radians(45.0))
        & (env.robot2object_dist > env.cfg.amp_cfg.thresh_robot2object)
    )
    return reward * active.float()

Config：

search_turn = RewTerm(func=walled4_env.search_turn_reward, weight=0.5)

说明：

env.base_ang_vel 是 upper body 坐标系下的角速度，不是 root link 的世界角速度。
仅转向分量奖励朝减小 bearing error 的方向转动；反方向转动时 turn_reward 为0，但朝向分量0.7 * heading_reward仍为正（active门控为真时）。
箱子一旦进入 ±45° 或机器人到箱距离不超过 0.7m，该项为 0；普通 walk_task 和抓取奖励一直生效。
没有 search 成功、search 超时或 search 失败的独立终止条件。

构造 box_z=0.54 或手中心距离 0.16m：held_hand_* 应为 0。

8. 常见复现错误

1. **在 `super()._reset_boxes()` 之前放墙/圆柱。** 这会读取旧的或未完成更新的机器人/箱子状态。
2. 在 env 构造时建立 curriculum 锚点。 这会使 warm-start 从绝对 iteration 计算，直接跳到高难度。
3. **把 `search_prob` 应用于所有回合。** 当前实现只作用于 `loco` 回合。
4. **以为 skill 概率包含 `pickUp=0.15`。** FindBox depth 实际是 `loco=0.8, pickUp=0.0, carryWith=0.2`。
5. **只把圆柱加进 scene，未加入 `depth_wall_prim_exprs`。** 物理上会碰撞，但 actor 看不到。
6. 启用未注册的 widened torque 函数。 当前 wall3/wall4 没有这个奖励。
7. **忘记 reward 会乘 `dt=0.02`。** 对比 reward 日志时不能直接用配置 weight 推算单步数值。
8. 新增观测维度。 wall3/wall4 不应为墙、圆柱或 search 标记增加 actor/critic 观测。
